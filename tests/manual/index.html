建议测试顺序

  1. 未授权：点击输入框不应出现自动菜单；点击扩展中的测试账户，应填入当前验证码。
  2. 确认已重新加载 2.1.4 或更新版本的扩展。在网页右键 → 扩展名称 → 在此网站启用自动菜单，确认 Chrome 授权。返回后重新聚焦输入框，应出现扩展菜单（设置中的页面内联菜单总开关需开启）。
  3. 刷新页面，再次聚焦；授权应继续生效。
  4. 扩展设置中撤销网站授权；已有菜单应消失，重新聚焦和刷新后均不应自动出现。
  5. 切换到六格、同源 iframe 和无字段场景，分别检查分格填充、iframe 填充、剪贴板回退。

两个测试网站： 127.0.0.1 · localhost。授权其中一个不会授权另一个。同一主机的不同端口不构成不同主机权限。

跨站 iframe 使用另一个主机名。先在新标签页打开 iframe 网站并授权它，再返回刷新本页。只授权顶层网站时，iframe 不应自动显示菜单。
