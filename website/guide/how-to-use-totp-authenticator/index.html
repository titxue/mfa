How to Use TOTP Authenticator on Chrome

TOTP Authenticator is a Chrome extension for generating two-factor authentication codes offline. It is designed for users who want a local-first authenticator on desktop, with QR import, one-click code copy, and simple account backup.

Install from Chrome Web Store

1. Install the Chrome extension

Open the Chrome Web Store listing and install the extension. After installation, pin it to the toolbar so you can open your 2FA codes during sign-in.

2. Add your first 2FA account

When a service shows a TOTP setup QR code, save or copy the QR image and import it in the extension. You can also paste an otpauth:// URI or enter the Base32 secret manually when a QR code is unavailable.

3. Copy and use a code

Open the extension, choose the matching account, and copy the current six-digit code. Paste it into the website's 2FA prompt before the countdown expires.

4. Back up accounts safely

Exporting accounts is useful when moving devices, but the backup file contains authenticator secrets. Store it only in a trusted location and remove old copies after migration.

5. Troubleshooting

  • If codes fail repeatedly, check that your computer time and timezone are accurate.
  • If a QR image cannot be read, try a clearer screenshot or paste the otpauth:// URI.
  • If accounts do not appear on another device, confirm Chrome sync is enabled.
