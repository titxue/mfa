How to Use TOTP Authenticator on Chrome

TOTP Authenticator is a Chrome extension for generating two-factor authentication codes offline. It is designed for users who want a local-first authenticator on desktop, with QR import, one-click code copy, and simple account backup.

Install from Chrome Web Store

1. Install the Chrome extension

Open the Chrome Web Store listing and install the extension. After installation, pin it to the toolbar so you can open your 2FA codes during sign-in.

2. Add your first 2FA account

When a service shows a TOTP setup QR code, save or copy the QR image and import it in the extension. You can also paste an otpauth:// URI or enter the Base32 secret manually when a QR code is unavailable.

3. Copy and use a code

Open the extension, choose the matching account, and copy the current six-digit code. Paste it into the website's 2FA prompt before the countdown expires.

4. Password protection and backup import

Enable password protection in settings with a master password of at least 8 characters. Account names, secrets, and websites are encrypted together. Lock manually or unlock after restarting the browser; closing the popup does not lock it.

Protected accounts export as encrypted JSON by default. Plain backups show the account count before import. For encrypted backups, enter the export password and choose “Decrypt and preview”, then check the count and confirm import. Duplicates are skipped; incorrect passwords or damaged files prevent import.

Plain backups expose secrets. Keep them safe. Forgotten passwords cannot be recovered, and changing the master password does not change passwords on old backups.

For cross-device sync, use the same extension and Chrome account with extension data sync enabled. Another device locks after receiving encrypted records; offline copies cannot be locked remotely immediately. Avoid editing accounts on multiple devices at once.

SHA1, 6 digits, and a 30-second period are supported. Unsupported QR parameters are rejected instead of silently using defaults.

5. Troubleshooting

  • If codes fail repeatedly, check that your computer time and timezone are accurate.
  • If a QR image cannot be read, try a clearer screenshot or paste the otpauth:// URI.
  • If accounts do not appear on another device, confirm Chrome sync is enabled.
