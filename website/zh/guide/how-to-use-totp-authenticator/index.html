如何在 Chrome 中使用 TOTP Authenticator

TOTP Authenticator 是一个用于离线生成双因素认证验证码的 Chrome 插件。 它适合希望在桌面浏览器中本地管理 2FA 账户的用户，支持二维码导入、 一键复制验证码和账户备份。

前往 Chrome Web Store 安装

1. 安装 Chrome 插件

打开 Chrome Web Store 页面并安装插件。安装后建议固定到浏览器工具栏， 这样登录网站时可以更快打开验证码列表。

2. 添加第一个 2FA 账户

当服务商显示 TOTP 设置二维码时，可以保存或复制二维码图片并导入插件。 如果没有二维码，也可以粘贴 otpauth:// URI，或手动输入 Base32 密钥。

3. 复制并使用验证码

打开插件，选择对应账户，复制当前六位验证码，并在倒计时结束前粘贴到 网站的 2FA 验证输入框中。

4. 密码保护与备份导入

在设置中开启密码保护，设置至少 8 位的主密码。账户名称、密钥和网站信息会一起加密。可手动锁定，浏览器重启后需要重新解锁；关闭弹窗不会锁定。

开启保护后默认导出加密 JSON。普通备份导入前会显示账户数量；加密备份先输入导出时的密码，点击“解密并预览”，查看数量后再确认导入。重复账户会被跳过，密码错误或文件损坏时不会导入。

明文备份会暴露密钥，请妥善保存。忘记密码无法恢复加密数据；修改主密码不会改变旧备份的密码。

跨设备需使用同一扩展、同一 Chrome 账号并开启扩展数据同步。另一台收到加密记录后才会锁定，离线副本不能立即远程锁定。请避免多设备同时编辑账户。

目前支持 SHA1、6 位数字和 30 秒周期。不支持的二维码参数会明确提示，不能强行按默认参数导入。

5. 常见排查

  • 如果验证码总是错误，先确认电脑时间和时区准确。
  • 如果二维码无法识别，尝试使用更清晰的截图，或粘贴 otpauth:// URI。
  • 如果另一台设备没有账户，请确认 Chrome 同步已开启。
