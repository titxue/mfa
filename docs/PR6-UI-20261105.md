# PR #6 高级设置界面

按照 emil-design-eng 的渐进展示与即时反馈原则调整添加/编辑窗口。常用操作保持直接；特殊参数需要用户主动展开。本次只改界面与交互，不改账户结构、密钥解析、加密或同步协议。

| Before | After | Why |
| --- | --- | --- |
| 类型、算法、位数、周期和网站与必填项同时展示 | 添加默认仅显示二维码入口、名称、密钥；特殊选项收进「高级设置」 | 减少普通添加过程中的选择负担。 |
| 内容过长，保存按钮在窗口外 | 标题和保存/取消固定，正文独立滚动；展开时将高级选项滚入视野 | 380×600 窗口内始终可完成或取消操作。 |
| 三个参数挤在同一行 | 标签与选择器按行排列 | 长语言标签和完整算法名称更易读。 |
| 编辑或扫码后全部参数展开 | 默认仍折叠，以「已自定义」标记特殊配置 | 遵循默认简单的要求；折叠只改变显示，不重置已有值。 |
| Steam 格式缺失只弹出提示 | 自动展开，定位格式控件并展示关联错误；重复提交也重新定位 | 用户能直接修正隐藏设置中的错误。 |
| 设置中的「导出所有版本」实际打开恢复页面 | 高级设置中明确命名为「恢复与历史备份」 | 与普通账户导出区分；当前迁移、冲突、待同步提示仍直接展示。 |
| 粘贴说明固定写 Ctrl+V | 12 语言均使用平台中立的粘贴/拖入说明 | Mac 与其他平台共享准确提示。 |

高级区域使用原生按钮与 `aria-expanded`/`aria-controls`，隐藏面板保留 React 状态；Enter/Space 沿用原生行为。展开滚动不抢走键盘焦点，减少动态效果时去掉移动过渡。使用 `100vh` 限高，与现有最低 Chrome 102 兼容。

验证覆盖浅/深色、键盘展开收起和焦点、每次重开默认折叠、扫码自定义参数直接保存、折叠编辑改名、修改后折叠保存、页脚位置、横向溢出、Steam 连续校验、恢复入口及既有商店流程。测试仅使用合成数据和隔离浏览器配置。
