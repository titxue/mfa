## 补充修复

- 恢复时保留选中和未选中的全部候选。请在解决冲突前导出所需版本；恢复完成后仍保留本机归档，但日常设置不再提供恢复历史入口。
- 写入失败或中断时，pending 状态可以导出和显式重试；异常数据保留原样，禁止普通保存覆盖。
- 当前启用加密时，选择明文恢复源需要密码并重新加密；启用保护会加密本机明文恢复副本。
- 新安装可以先设置密码，再添加账户；单纯打开界面不会创建空同步仓库。
- 远端修改密码或关闭保护时清除失效的本机会话密钥。
- 内容脚本不能调用迁移、恢复清单、恢复导出或冲突解决接口。

## 安全审查和剩余限制

从原 PR 基线 `8f6c307` 到修复后的全部差异，未新增网络调用、manifest 权限、依赖或锁文件变化。新增恢复接口仅允许扩展 popup 调用；内容脚本收到摘要和按需验证码，不收到密钥或恢复文件。这是限定范围的代码与测试检查，不构成“绝对没有后门”的保证。

Chrome Sync 没有跨设备 CAS 或同步完成标记。未被新客户端观察到的旧设备写入，仍可能与迁移标记/清理竞争而丢失；旧客户端没有恢复日志。新客户端的未同步分支可能只能从原设备的本机日志恢复。卸载、清空本机存储或遗失密码会影响恢复。协议测试模拟这些顺序，并非真实 Google 云同步的多设备验收。

不同版本中的同名冲突需要人工决定保留哪个密钥/参数；不自动猜测合并。组合 `mfa-recovery` 导出是归档文件，单个候选导出才是可直接导入的普通备份。详细协议、用户步骤与原子性窗口见 [OTP-PARAMETER-COMPATIBILITY.md](OTP-PARAMETER-COMPATIBILITY.md)。
