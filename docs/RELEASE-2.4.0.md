## 本次更新

- 支持 SHA1／SHA256／SHA512、6／8 位，以及 15–120 秒周期；Steam 固定参数保持不变。
- 特殊参数默认收在高级设置中，网站地址放在账户名称下方。
- 新账户库隔离旧版客户端写入，升级需要明确确认；同步冲突保留恢复和导出数据。
- 修正恢复页读取失败时误显示“等待同步”的提示，正常设置移除重复恢复入口。

## 升级与账户保留

在相同临时浏览器 profile、固定扩展目录中，以 2.3.9 发布源码重建产物升级到本上传包。普通 V1、加密 V1、旧 `accounts` 三组各 6 个合成账户全部通过：

- 扩展 ID 相同；名称（含空白和冒号）、密钥、Steam 类型、网站和顺序保留。
- 固定时间验证码、语言、主题、自动填充设置一致。
- 首次读取要求明确确认迁移，确认前原同步数据不变。
- 加密库保持加密，迁移后的密文内容不变；错误密码不写回，原密码可解锁。
- 标准账户导出及原始恢复导出可用。解决冲突前应先导出所需版本，日常设置不再提供历史恢复入口。

旧 2.3.9 ZIP 已不在本机，因此旧产物由提交 `8f6c3075b531f2eed99a3a01203fe24cb7bb4232` 重建，并非重新下载的官方商店产物。为使临时 Chromium 使用更新后的后台脚本，仅清理该临时 profile 的 Service Worker 缓存，local／sync 扩展存储保留。本次未访问真实账户或日常浏览器资料。

Chrome Sync 没有跨设备 CAS；离线旧设备、未观察到的写入及同步到达顺序仍有竞争窗口。现有协议保留已观察到的候选、失败写入和恢复副本，但不保证跨设备绝对零丢失。本次没有验收真实在线同步或商店实际分发升级。详见 `docs/OTP-PARAMETER-COMPATIBILITY.md`。
